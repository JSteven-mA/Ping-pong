## Alcance de este hito
Esta entrega construye la base visual y estructural del juego. Dibuja la escena
inicial (tablero, dos paletas, pelota y marcador en 0 - 0) y no incluye
movimiento, teclado ni colisiones, que corresponden al Proyecto Final.

## Compilación y ejecución
1. Descargar la suite de https://www.nand2tetris.org (requiere Java).
2. Compilar la carpeta con `JackCompiler`:
   ```
   JackCompiler.bat ruta\a\PingPong_Hito1
   ```
3. Abrir `VMEmulator`, usar *File > Load Program* y seleccionar la carpeta.
4. Elegir la animación *No animation* y pulsar *Run*.

Resultado esperado: tablero con muros, línea central y anillo; paleta izquierda
y derecha; pelota en el centro; marcador "JUGADOR: 0" y "CPU: 0" arriba.

## Teclas
Este hito no usa teclado. El control se implementa en el Proyecto Final.
